# App icons

Dawn Shield exports, from the marketing master — not traced. Brand: charcoal `#171E26`, red `#C8102E`, gold `#E8A33D`.

| File | Size | Notes |
|---|---|---|
| `icon-192.png` | 192×192 | Home screen, and the manifest's minimum for installability. |
| `icon-512.png` | 512×512 | Splash and high-density launchers. |
| `icon-maskable-512.png` | 512×512 | Mark inside the 80% safe zone; charcoal fills the rest. |
| `icon-1024.png` | 1024×1024 | Store listing master. No transparency, no rounded corners. |

`web/public/favicon.svg` is the same mark. Bubblewrap reads the 512s from the web manifest.
